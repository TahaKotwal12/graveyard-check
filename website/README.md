# Graveyard Check website

Marketing/docs site for [Graveyard Check](../README.md). Vite + React + Tailwind CSS.

## Develop

```bash
pnpm install
pnpm dev
```

## Deploy to Vercel

1. Import the repository in Vercel.
2. Set **Root Directory** to `website`.
3. Framework preset: **Vite** (build command `pnpm build`, output directory `dist` — detected automatically).

No environment variables or rewrites needed; it's a fully static single-page site.
